# Cooking Made with Love

Landing page for a home bakery selling artisan bread and sweet treats at the
Packard Farmers Market (Shelby Township, MI).

**Live site:** https://cookingmadewithlove.netlify.app

## How this works

- `index.html` is the entire site — a single static page, no build step.
- Pushing to `main` auto-deploys to Netlify (Site is linked under
  Netlify → Project configuration → Build & deploy → Continuous deployment).
- `robots.txt` / `sitemap.xml` are for search engine indexing.
- `og-image.jpg` is the preview image used when the link is shared on social
  media (Open Graph / Twitter Card).

No dependencies, no build tools — just edit `index.html` and push.
